# AffixPrism v0.4.0-beta.9

ExileLens is now **AffixPrism**, with a new logo, application/tray icons and a matching charcoal-green and gold theme.

- Improved item cards with larger text, section dividers and clearer base names in item checks and seller comparisons.
- Corrected charm duration, charge, immunity and usage-text styling.
- Downloaded updates are remembered across restarts, with a clearer **Install update and restart** action.
- Added a persistent update banner, tray notifications and release checks every 30 minutes when enabled.
- Existing settings, bookmarks and character data migrate automatically on first launch; the original data stays intact.

**Upgrading from ExileLens:** after the repository rename, old updaters cannot recognise the new download address. Download **AffixPrism-0.4.0-beta.9-win-x64.zip**, exit the old tray application, extract the entire ZIP and run **AffixPrism.exe**. Future AffixPrism releases use the new update feed. The identically packaged ExileLens ZIP is a compatibility alias for the transition.

Windows x64; .NET is bundled. Rune OCR may require the Microsoft Visual C++ 2015-2022 x64 runtime.
