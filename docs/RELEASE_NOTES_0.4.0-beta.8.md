## Improvements

- Compact currency checks show stock, exchange ratios and seven-day price trends, with unit and stack values on hover.
- Granted-skill filters such as level 20 Sigil of Power now run on the trade server before listing pagination.
- Listing pages use the server's available rate-limit budget instead of an unconditional four-second pause. Server cooldowns and fallback pacing remain enforced.
- Multi-line socket effects now resolve together: Rune of Foundations includes its Energy Shield effect and can be identified alongside other socketed augments.
- Anoints use light blue and ordinary implicit modifiers use violet in item checks and comparisons.
- Items marked Foil Unique gain an iridescent header and animated rainbow colouring, with a static effect when Windows animations are disabled.

Validation: 312 automated checks and Windows UI smoke checks. Prices remain indicative asking prices; live offer counts depend on your filters and available listings.
